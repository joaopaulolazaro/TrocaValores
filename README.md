# 🔄 Algoritmo de Troca de Valores (Swap) em Java

Repositório desenvolvido para fins acadêmicos, contendo a implementação da lógica de inversão de valores entre duas variáveis utilizando uma variável auxiliar temporária (aux). O exercício faz parte das atividades práticas da disciplina de programação.

---

## 📋 Sobre o Projeto

O programa realiza a leitura de dois valores inteiros fornecidos pelo usuário através da entrada padrão (Scanner) e executa a troca segura dos conteúdos entre as variáveis a e b utilizando uma terceira variável de suporte para evitar a perda de dados.

---

## ⚙️ Como Executar

1. Abra o projeto no *IntelliJ IDEA* (ou na sua IDE Java preferida).
2. Localize o arquivo TrocaDeValores.java dentro da pasta src.
3. Execute a classe principal para interagir com o console.
